# 📖 Glossário de Machine Learning para Iniciantes

## 🔑 Termos Essenciais

- **Dataset**: conjunto de dados usado para treinar e testar modelos.  
- **Feature (atributo)**: variável de entrada usada pelo modelo para aprender padrões.  
- **Label (rótulo)**: saída esperada em problemas supervisionados.  
- **Supervised Learning**: aprendizado com dados rotulados (ex: classificação, regressão).  
- **Unsupervised Learning**: aprendizado sem rótulos, focado em encontrar padrões (ex: clustering).  
- **Overfitting**: quando o modelo aprende demais os dados de treino e perde capacidade de generalização.  
- **Underfitting**: quando o modelo não consegue capturar padrões relevantes dos dados.  
- **Bias (viés)**: tendência sistemática de erro em um modelo.  
- **Variance (variância)**: sensibilidade do modelo a pequenas variações nos dados.  
- **Model Training**: processo de ajuste dos parâmetros do modelo para aprender com os dados.

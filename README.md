# 📘 Miniguia de Estudos: Machine Learning para Iniciantes

## 📌 Contexto e Objetivos
Este repositório foi criado como parte do desafio da DIO para explorar o uso da Inteligência Artificial como ferramenta de aprendizagem ativa.  
O tema escolhido é **Machine Learning para Iniciantes**.  

**Objetivos:**
- Entender os conceitos fundamentais de Machine Learning.  
- Organizar conhecimento de forma estruturada e prática.  
- Criar um guia com glossário e prompts reutilizáveis para futuras revisões.  

---

## 📚 Curadoria de Fontes

## 🤖 Engenharia de Prompts e Cicatrizes
Durante o processo, foram testadas diferentes variações de prompts para extrair respostas da IA.  

**Exemplos de perguntas estratégicas:**
- “Explique regressão linear em linguagem simples.”  
- “Quais são os principais algoritmos supervisionados e suas aplicações?”  
- “Crie um resumo estruturado com exemplos práticos de classificação.”  

**Dificuldades encontradas (troubleshooting):**
- Respostas muito genéricas → solução: adicionar contexto no prompt.  
- Informações desatualizadas → solução: validar com fontes confiáveis.

## 📖 Miniguia de Estudo (Entrega Final)

### 🔹 Resumos Estruturados
- **Regressão Linear:** modelo para prever valores contínuos.  
- **Classificação:** algoritmos como KNN, SVM e Árvores de Decisão.  
- **Clustering:** agrupamento não supervisionado (ex: K-Means).  

### 🔹 Glossário
- **Dataset:** conjunto de dados usado para treinar/testar modelos.  
- **Feature:** variável de entrada usada no modelo.  
- **Overfitting:** quando o modelo aprende demais os dados de treino e perde generalização.  
- **Underfitting:** quando o modelo não consegue capturar padrões relevantes.  
- **Supervised Learning:** aprendizado com dados rotulados.  
- **Unsupervised Learning:** aprendizado sem rótulos.  
- **Model Training:** processo de ajuste dos parâmetros do modelo.  
- **Validation Set:** dados usados para ajustar hiperparâmetros.  
- **Bias:** tendência sistemática de erro.  
- **Variance:** sensibilidade do modelo a pequenas variações nos dados.  

### 🔹 Prompts Reutilizáveis
- “Resuma os 5 principais conceitos de Machine Learning.”  
- “Crie flashcards para revisar algoritmos supervisionados.”  
- “Liste exemplos práticos de aplicação de Machine Learning no mercado.”
